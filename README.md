# Troxy for Claude Code

Troxy keeps your Claude usage bar going longer.

## Install

In Claude Code, run:

```
/plugin install troxy-guard --marketplace troxy-hq/troxy-plugin
```

Then start a new message. Troxy shows a code: open the link, sign in at dash.troxy.io and approve it. That's it, no key to copy.

Pause any time with `/troxy off`, resume with `/troxy on`.

This repo is synced automatically from the Troxy CLI. Docs: https://docs.troxy.io
